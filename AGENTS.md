# Instrucciones del agente
- Se breve y conciso.
- Utiliza siempre el español para razonar, comunicarte y programar.
-  Asegurate de tener inicializado el servidor de tiddlywiki con el comando "tiddlywiki mywikifolder --listen port=8090" donde mywikifolder es el folder de la wiki, por ejemplo /home/dev/projects/70_Fast_TW_SDD/MyMiki
-  cada vez completes alguna tarea solicitada por mi, actualiza el fichero /home/dev/projects/70_Fast_TW_SDD/tiempos-speckit.md indicando en una tabla el | Comando | Tiempo activo |
- Si quieres ejecutar o comprovar funcionalidades desde un navegador, usa Playwright, Puppeteer o Chromium, con el navegador con interfaz visible (modo headed); no uses modo headless. por ejemplo En Playwright, especifica `headless: false` al lanzar el navegador. En Puppeteer, especifica `headless: false`. Al ejecutar Chromium directamente, no uses opciones como `--headless`.
